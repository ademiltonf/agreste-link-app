# App Agreste Link (Android)

App da Central do Assinante da Agreste Link Fibra. Ele abre o app web
(https://agreste-app.ademilton41.workers.dev) numa tela própria, sem barra de navegador.
Links de WhatsApp, boleto e Fast.com abrem no app certo do celular.

## Como gerar o APK
Todo envio para a branch `main` gera um APK automaticamente (aba **Actions**).
O APK fica para baixar em **Releases**.

> A chave `app/teste.keystore` é só para testes. Para publicar na Play Store,
> vamos criar uma chave própria e guardá-la nos *Secrets* do repositório.
